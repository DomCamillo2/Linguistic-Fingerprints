# Notebook sequence

Planned narrative:

1. `01_corpus_audit.ipynb` — coverage, provenance, failures, and length compliance.
2. `02_feature_validation.ipynb` — distributions, manual audit, and frozen feature list.
3. `03_group_comparisons.ipynb` — paired earlier/later contrasts and uncertainty.
4. `04_cross_genre.ipynb` — leave-one-task-type-out evaluation by family.
5. `05_cross_family.ipynb` — bidirectional transfer and unseen-prompt robustness.
6. `06_baselines_and_sensitivity.ipynb` — prompt-blocked baseline, length sensitivity, PCA, and optional clustering.
7. `07_report.ipynb` — final research narrative, transfer failures, and limitations.

Reusable logic belongs in `src/`, not hidden in notebook cells.
