# Notebook sequence

Planned narrative:

1. 01_corpus_audit.ipynb — coverage, provenance, failures, formatting, and length.
2. 02_feature_validation.ipynb — distributions, manual audit, and the frozen 15-feature list.
3. 03_paired_comparisons.ipynb — later-minus-earlier contrasts, bootstrap intervals, and corrected paired tests.
4. 04_prompt_blocked_classification.ipynb — within-family grouped cross-validation and dummy baselines.
5. 05_leave_one_task_type_out.ipynb — task-type robustness by family.
6. 06_length_and_optional_pca.ipynb — length sensitivity and optional scaled PCA.
7. 07_report.ipynb — final narrative, null results, and limitations.

Reusable logic belongs in src/, not hidden in notebook cells. Mixed models, required clustering, and cross-family transfer are outside the current proposal.
